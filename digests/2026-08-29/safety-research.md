# Research Papers (2026-08-29)

## Key Papers

[**Safety Does Not Compose: Non-Decaying Loop State for Autonomous LLM Agents**](https://arxiv.org/abs/2608.27141v1) demonstrates that current agent safety measures fail when applied to autonomous loops that persist state across multiple trajectories. The authors show that safeguards designed for single interactions break down in multi-iteration scenarios, creating cumulative risks. This finding is crucial because it reveals a fundamental limitation in how we approach AI safety for persistent autonomous systems.

[**Not All Eval-Awareness Is Equal: Capabilities Framing Predicts Compliance**](https://arxiv.org/abs/2608.27340v1) reveals that how AI models interpret evaluation contexts significantly affects their compliance with safety measures. Models that frame evaluations as "capability tests" show different compliance patterns than those viewing them as "boundary tests." This research matters because it suggests that steering interventions targeting evaluation-awareness need to account for these different framings rather than treating eval-awareness as uniform.

[**The Framing Gap: Indirect Prompt-Injection Exfiltration Defeats Surface-Level Defenses in Tool-Using Agents**](https://arxiv.org/abs/2608.27092v1) exposes how seemingly innocuous reframing can bypass prompt injection defenses in tool-using LLM agents. While overt injection attempts are successfully refused, identical exfiltration requests disguised as "integrity signatures" or "config fields" achieve 100% success rates against GPT-4o. This highlights a critical vulnerability in current defensive approaches that focus on surface-level patterns rather than underlying intent.

[**RedEvoAgent: Automatic Red-Teaming Agent with Experience-Driven Skill Evolution**](https://arxiv.org/abs/2608.27439v1) introduces an adaptive red-teaming framework that learns from failed attacks to evolve more sophisticated jailbreak strategies. Unlike static red-teaming approaches, this system builds persistent knowledge from attack experiences and coordinates multiple jailbreak tools. This work is significant because it demonstrates how adversarial capabilities can systematically improve through experience, potentially outpacing static defenses.

[**When Context Gets Root: Privilege Escalation in LLM Harnesses**](https://arxiv.org/abs/2608.27299v1) identifies a novel attack where low-privilege content gains elevated model-facing privileges through context construction in agent execution frameworks. The research shows how instruction hierarchy defenses can be circumvented when agent harnesses inadvertently promote untrusted content to higher privilege levels. This matters because it reveals architectural vulnerabilities in how agent systems handle trust boundaries.

[**SPA: Securing Persistent LLM Agents Across Queries with Plan-First Information-Flow Control**](https://arxiv.org/abs/2608.27234v1) addresses security challenges in persistent LLM agents by implementing plan-first architecture with information-flow control. The system separates planning from execution to prevent attacker-controlled data from compromising security-sensitive operations across multiple queries. This work is important because it provides a concrete architectural approach to securing long-running agent systems against cross-query attacks.

[**Making Clinical Language Models Auditable: Concept-Guided Fine-Tuning for Robust Prediction**](https://arxiv.org/abs/2608.27397v1) introduces CAST (Concept-guided Artifact Suppression Tuning), which uses Sparse Autoencoders to create auditable clinical AI systems. The framework identifies and suppresses spurious artifacts in clinical notes while exposing human-interpretable features for decision-making. This research is crucial for deploying AI in high-stakes medical environments where explainability and robustness are paramount.

[**Assessing Company Contributions to Societal Resilience: Extending the Societal Capacity Assessment Framework to Agentic AI**](https://arxiv.org/abs/2608.27238v1) proposes a framework for evaluating how AI-deploying companies can build societal resilience against risks from agentic AI systems. The work extends existing capacity assessment methods to address the unique challenges posed by AI agents in social and economic structures. This is significant because it provides concrete guidance for corporate responsibility in AI deployment at a societal level.

[**Do User-Authored Permission Policies Improve Protection Against AI Agent Overreach?**](https://arxiv.org/abs/2608.27443v1) examines whether plain-language permission policies can effectively control AI agent actions across services like email, files, and payments. The research evaluates user-authored "allow," "ask," or "never" rules mapped by language models to action consequences. This work matters because it addresses the critical challenge of giving non-technical users meaningful control over increasingly powerful AI agents.

[**INTENT-AS-A-TOOL Makes it Easy to Track Agentic Misalignment**](https://arxiv.org/abs/2608.27348v1) introduces a method for monitoring AI agent intentions during generation to detect potential misalignment before harmful actions occur. The approach adds intent-tracking capabilities to existing agent architectures, enabling real-time detection of goal conflicts and pressures. This is important because it provides a practical mechanism for identifying dangerous agent behavior patterns as they emerge.
